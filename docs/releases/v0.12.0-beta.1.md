# Silent Orbit v0.12.0-beta.1 — personal aesthetic customization candidate

`v0.12.0-beta.1` is a local release candidate prepared from the Private
source repository. It is not a formal Public release until the deterministic
Public Export, Public PR, required `release-gate`, merge to Public `main`, and
Git-connected Netlify production chain all complete.

Independent-user acceptance has not started for this candidate. Automated
tests, author review, fixtures, and visual QA are engineering evidence only.
The dormant Chinese checklist and Issue Form are included for later activation;
their presence is not acceptance evidence.

## What changed

- Added CLI interface `0.5.0` with `capabilities` and
  `customize status|prepare|decide|refresh|doctor`.
- Added the independent `customize-skill-cosmos` Agent Skill.
- Added a short summarized aesthetic profile that never stores the raw
  interview, prompts, absolute local paths, or private Skill state.
- Requires exactly two functional directions that differ on at least two
  structural axes. Color-only variants are rejected.
- Added immutable `keep`, `adjust`, `reject`, and `redo` decision history.
- Keeps preview rounds under `customization/rounds/`, selected output under
  `customization/current/`, and private state under
  `.silent-orbit/customization/`.
- Refreshes only `site-data.json` and `frontend-handoff.v2.json`; style files
  must retain the selected digest or refresh stops without replacing current
  output.
- Adds `frontend-handoff.v2.json` to normal generator output while preserving
  the frozen v1 generator contracts.

## Compatibility and privacy

- Existing v1 project, inventory, library, and site-manifest Schemas remain
  byte-for-byte locked by `schemas/schema-lock.v1.json`.
- The new customization contracts are additive v2 sidecars locked by
  `schemas/schema-lock.v2.json`.
- Existing generated projects can be regenerated to obtain the v2 handoff;
  no v1 state migration is performed.
- Customization does not install, update, remove, freeze, or restore Skills.
- Customization does not publish, open a PR, or deploy.

## Candidate versions

- Package / repository: `0.12.0-beta.1`.
- CLI interface: `0.5.0`.
- Runtime: Node.js 24.
- Generator contracts: frozen v1.
- Customization contracts: additive v2 sidecars.

## Release and acceptance boundary

Do not treat this candidate as formally released based on a local tarball,
author dogfood, automated agents, or generated previews. Begin independent
user testing only after the candidate is exported, reviewed through the Public
PR release chain, and explicitly activated for acceptance.
