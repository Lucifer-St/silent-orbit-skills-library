# Silent Orbit v0.11.0-beta.7 — governance and public-document repair

`v0.11.0-beta.7` is a GitHub Pre-release candidate generated from the Private
source of truth. It incorporates the useful documentation structure proposed
in public PR #10 without treating the contributor branch, generated files,
automation, or author testing as independent-human acceptance.

## What changed

- Reorganized Public documentation under `docs/guides`, `docs/policies`,
  `docs/testing`, `docs/releases`, `docs/audits`, and timestamped `docs/notes`.
- Kept a deterministic source-to-Public path map so Private source paths remain
  authoritative and generated manifests and receipts are never hand-edited.
- Included the complete Public `docs` tree in the release tarball and added
  relative-link validation so repository links cannot become package-only
  dead ends.
- Added Public `CODEOWNERS` coverage for release, workflow, Schema, package, and
  Netlify control paths.
- Pinned every GitHub Action to an immutable full commit SHA and disabled
  checkout credential persistence.
- Preserved the `0.4.0` CLI interface and locked v1 Schema family; no migration
  is required from `v0.11.0-beta.6`.

## Acceptance boundary

This candidate remains pre-v1. PR review, contributor testing, author testing,
CI, deterministic export checks, and agent-assisted verification are release
evidence only. They do not satisfy the required independent-human end-to-end
acceptance for v1.

## Distribution

- GitHub Pre-release assets only.
- No npm registry publication.
- Production only through Public GitHub `main`, the required
  `release-gate`, and the existing Git-connected Netlify site.
- No direct deployment from Private source and no manual Netlify Production
  deploy.
