# Silent Orbit v0.13.0-beta.1 — novice customization and structural-redesign RC

`v0.13.0-beta.1` is a new immutable prerelease generated from the Private source. It does not rewrite or reuse `v0.12.0-beta.1`.

## What changed

- CLI `0.6.0` adds read-only customization preflight, explicit project-only consent, resumable one-question novice interviews, plain-language confirmation, and natural-language feedback.
- Preferred map/library navigation controls first open, refresh, mobile rendering, and kept output while remaining distinct from an explicit runtime switch.
- `restyle`, `adjust`, and `redesign` are separate operations. A redo must change public structure data—node positions, groups, edges, or layout strategy—and a CSS-only change is rejected.
- Candidate A/B styling uses semantic surfaces, contrast-safe dark/light tokens, and renderer-sized focus-map spacing so nodes do not overlap.
- Frozen v1 and v2 schemas are unchanged. Additive v3 companions have a separate lock and migration statement.
- The Release includes `SILENT_ORBIT_NOVICE_HUMAN_TEST_PACK.zh-CN.md`, which can produce a privacy-safe, validator-checked Customization Issue Form equivalent receipt without requiring a GitHub account.
