# Silent Orbit v0.11.0-beta.8 — executable human handoff repair

`v0.11.0-beta.8` is a GitHub Pre-release candidate generated from the Private
source of truth. It repairs the release handoff after three independent people
were blocked before the core product flow: two received an unresolved template,
and one verified the previous tarball but found that its required handoff
contract was missing.

Those results are real independent defect discovery, not completed independent
acceptance. Contact names, avatars, chat screenshots, local paths, and raw logs
are intentionally excluded from this release.

## What changed

- Added one human-facing Chinese entry point:
  `V1_RC_ONE_FILE_HANDOFF.zh-CN.md` in the GitHub Release assets.
- The same rendered contract is committed under
  `docs/testing/v1-rc-one-file-handoff.zh-CN.md` and included in the tarball.
- Export fails on unresolved release tokens. Package smoke fails when the
  installed contract is missing, contains tokens, has the wrong version, or
  differs from the expected Release asset.
- The handoff is UTF-8 with BOM and tells Windows agents to read it explicitly
  as UTF-8. Contract comparison ignores only an optional leading BOM and line
  ending differences.
- The first screen now tells a tester that no command entry or template editing
  is required: download one file, upload it to a local Agent, and say
  `开始验收`.
- Release assets are staged from the exact Public files by one deterministic
  script, which writes `SHA256SUMS.txt` for the tarball and every handoff asset.

## Compatibility

- Package / repository: `0.11.0-beta.8`.
- CLI interface: `0.4.0` (unchanged).
- Runtime baseline: Node.js 24.
- v1 Schema hashes and compatibility family are unchanged; no migration is
  required from `v0.11.0-beta.7`.
- Native Windows, Linux, and macOS are supported. Docker requires an explicit
  host Skills mount. The hosted site is browse-only.

## Distribution and rollback

- GitHub Pre-release assets only; the npm registry remains unpublished.
- Production remains Public GitHub `main` through the required `release-gate`
  and Git-connected Netlify. No direct or manual Netlify deployment is allowed.
- Roll back to immutable `v0.11.0-beta.7` if this candidate introduces a new
  release defect. Do not rewrite either tag or Release.

## Acceptance boundary

This repair returns the project to the independent-human handoff point. CI,
author checks, deterministic export, package smoke, Docker smoke, and hosted UI
smoke are engineering evidence only. `v1.0.0` remains NO-GO until a genuinely
independent person completes the full released flow with no P0/P1 issue.
