# Silent Orbit v0.13.1-beta.1 — release-chain and Skill contract hardening

`v0.13.1-beta.1` supersedes the immutable `v0.13.0-beta.1` prerelease. The
earlier Release asset contained a candidate handoff receipt; this new version
requires a finalized `Public Release status: GO` receipt before any uploadable
asset can be prepared.

## What changed

- Five bundled Agent Skills now share one fail-closed package validator for
  frontmatter, UI metadata, relative references, private-path safety, and
  package/CLI compatibility.
- Build and audit Skills can discover a project-local installation without an
  implicit network download. Project `HealthReportV1` audits and live global
  library maintenance now have explicit, non-overlapping trigger guidance.
- Release export cannot overwrite a finalized RC. Asset preparation
  verifies the GO receipt, source commit, and manifest digest before packaging.
- Netlify Deploy Previews use the same production build as `main`, and private
  catalog data receives an explicit 404 instead of an SPA soft-404.
- English and Chinese READMEs expose the customization Skill, architecture,
  verification evidence, and portfolio-ready project outcomes.

## Compatibility

- Package: `0.13.1-beta.1`
- CLI interface: `0.6.0` (`0.6.x` compatibility family)
- Runtime: Node.js 24 on Windows, Linux, and macOS release gates
- Contracts: frozen v1/v2 plus additive v3; no migration is required

## Status

This is a prerelease, not `v1.0.0`. Automated checks, maintainer UAT, Agent
rehearsal, and release smoke do not count as independent human acceptance.
`v1.0.0` remains NO-GO until a valid independent report is received and all
P0/P1 findings are fixed and independently retested.
